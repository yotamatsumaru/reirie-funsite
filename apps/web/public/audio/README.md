# あっち向いてホイ サウンド

このフォルダにゲームの音声ファイルを配置します。

## 効果音 (SE) — 配置済み

| ファイル | 用途 |
|---|---|
| `se-tap.mp3`   | ボタンタップ音 |
| `se-win.mp3`   | 勝ちファンファーレ |
| `se-lose.mp3`  | 負け音 |
| `se-draw.mp3`  | あいこ音 |
| `se-point.mp3` | ポイント獲得音 |

効果音は最初から有効です（`sounds.ts` の `SE_ENABLED = true`）。

## キャラクターボイス (REIRIE) — 収録音源を差し替える

収録した音声を **下記のファイル名** でこのフォルダ (`apps/web/public/audio/`) に置いてください。

| ファイル名 | シーン | セリフ例 |
|---|---|---|
| `voice-start.mp3` | ゲーム開始（手を選んだ時） | 「じゃんけん、いくよ〜！」 |
| `voice-acchi.mp3` | あっち向いてホイ（方向を選んだ時） | 「あっち向いて…ホイ！」 |
| `voice-win.mp3`   | プレイヤーの勝ち | 「わっ、負けちゃった〜！やるね！」 |
| `voice-lose.mp3`  | プレイヤーの負け | 「えへへ、私の勝ち♪」 |
| `voice-draw.mp3`  | あいこ | 「あれ、同じだ！もう一回！」 |

### 差し替え手順

1. 上記ファイル名の mp3 をこのフォルダに置く。
2. `apps/web/src/app/(members)/me/games/acchi/sounds.ts` を開き、
   `export const VOICE_ENABLED = false;` を **`true`** に変更する。
3. デプロイ（ビルド）すればボイスが再生されます。

> ファイルが無くても、`VOICE_ENABLED = true` にしていても、
> 該当ボイスが存在しない場合は自動でスキップされるため、
> 一部だけ差し替えても安全に動作します。

### 収録のおすすめ仕様

- 形式: **mp3**（44.1kHz / モノラルまたはステレオ）
- 長さ: 各 **1〜2秒**程度（掛け声・短いセリフ）
- 音量: 割れない範囲でしっかりめに。ノーマライズ推奨。
- 無音の余白（頭・お尻）はできるだけカットするとテンポよく鳴ります。
