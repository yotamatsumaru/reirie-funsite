# あっち向いてホイ サウンド

## 効果音 (SE) — このフォルダに固定配置

| ファイル | 用途 |
|---|---|
| `se-tap.mp3`   | ボタンタップ音 |
| `se-win.mp3`   | 勝ちファンファーレ |
| `se-lose.mp3`  | 負け音 |
| `se-point.mp3` | ポイント獲得音 |

効果音はコード同梱の静的ファイルです（差し替えたい場合はここを置き換え）。

## キャラクターボイス (REIRIE) — 管理画面からアップロード

キャラボイスは **管理画面 `/super-admin/game` の「あっち向いてホイ ボイス」** から
アップロードします。**コードの編集やデプロイは不要**です。

保存先は本番構成に合わせて自動判定します:
- S3 アセットバケットが設定済み → S3 に保存
- 未設定 → DB に保存し `/api/media/game-audio/{id}` 経由で配信

### スロット（アップロード枠）

| スロット | シーン | セリフ例 |
|---|---|---|
| ゲーム開始 (`voiceStart`) | ミニゲームを開いたとき | あっちむいてホイ、いくよ〜！ |
| あっちむいてPU (`voiceAcchi`) | 方向を選んで「あっちむいてPU」を仕掛けるとき | あっちむいて…PU！ |
| ファンの勝ち (`voiceWin`) | プレイヤーが勝ったとき (方向が一致) | わっ、負けちゃった〜！キミ、やるね♪ |
| ファンの負け (`voiceLose`) | プレイヤーが負けたとき (方向が不一致) | えへへ、私の勝ち♪ |
| もう一度 (継続) (`voiceAgain`) | 「もう一度遊ぶ」ボタンを押して続けて遊ぶとき | もう一回やろっ！次は負けないよ〜！ |
| またね (終了) (`voiceBye`) | 「会員カードに戻る」ボタンを押してゲームを離れるとき | またね〜！また遊んでね♪ |

未アップロードのスロットは自動でスキップされます（効果音のみで動作）。

### 収録のおすすめ仕様

- 形式: **mp3**（wav / ogg / m4a / aac / webm も可）
- サイズ: **5MB 以内**
- 長さ: 各 **1〜2秒**程度（掛け声・短いセリフ）
- 頭・お尻の無音はカット気味に。音量はノーマライズ推奨。
