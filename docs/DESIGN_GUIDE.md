# ReiRieRoom — デザインガイド

REIRIE 公式ファンクラブサイト **ReiRieRoom** のデザイン仕様書。
アーティスト REIRIE（黒宮れい × 金子理江）の世界観に基づく。

---

## 🎨 コンセプト（2026 リニューアル: City Editorial）

**「The Amethyst Room — City Editorial」**

2026年7月、[cityxofxangels.com](https://cityxofxangels.com/?ref=onepagelove) を参考に、
トンマナを大胆・エディトリアル（雑誌的）な方向へ刷新。
ファンクラブ = ファンだけが入れる "紫水晶の部屋" というコンセプト自体は継続しつつ、
表現は「甘さ・ふわっと感」から「太字タイポグラフィ・フラットな配色・余白を活かした大胆な構成」へ変更。

- 背景はラベンダー（薄紫）、ポイントカラーはマゼンタピンクの2色を基調としたフラットな配色
- 文字色は黒に統一し、視認性とコントラストを重視
- カードは角丸を抑え、黒枠＋ドロップシャドウのネオブルータリズム調
- サイドバーなど既存の UI 構造（ナビゲーション等）はそのまま維持し、配色とタイポグラフィのみを刷新

> 旧デザイン「Rosy Twilight」（グラスモーフィズム・グロー・パステルグラデーション）からの移行。
> 旧デザインの記録は本ファイル末尾の「旧デザイン（アーカイブ）」を参照。

## 🎨 カラーパレット（City Editorial）

| 役割 | 名称 | HEX | 用途 |
|---|---|---|---|
| 背景 | Base Lavender | `#B9B2D8` | ページ背景（水色っぽい薄紫） |
| ポイントカラー | Point Magenta | `#C263A2` | ボタン・リンク・アクセント・見出しの一部 |
| 基本文字色 | Ink Black | `#000000` | 本文・見出し・カードの黒枠 |
| カード面 | White | `#FFFFFF` | カード背景・コントラスト確保 |

旧パレット（Rosy Twilight）のクラス名（`twilight-rose` 等）は互換性のため CSS変数名としてそのまま残しているが、
実際の色は上記 City Editorial の値に置き換わっている（`apps/web/src/app/globals.css` の `@theme` ブロック参照）。

### 配色ルール
```css
/* ページ背景 */
background: #B9B2D8;

/* 主要ボタン・強調要素 */
background: #000000; /* 黒地に白文字、ホバーでポイントカラーへ */
color: #C263A2;       /* リンク・ラベル・数字などのアクセント */
```

## ✍️ タイポグラフィ

| 用途 | フォント | 備考 |
|---|---|---|
| 全般（英字・日本語共通） | **ゴシック体**（ヒラギノ角ゴ ProN / Hiragino Sans をベースに、Web フォントは Zen Kaku Gothic New） | 太字（700〜900）を多用し、力強いエディトリアル感を演出 |
| 見出し | 同上・大文字（uppercase）・広めのトラッキング | `cityxofxangels.com` を参考にした雑誌的な迫力 |
| 数字・ラベル | 同ゴシック体の極太ウェイト、アウトライン数字も使用 | `01 / 02` 連番表記（特典セクション等） |

旧デザインで使用していた Cormorant Garamond（セリフ）・Shrikhand（装飾）・Zen Maru Gothic（丸ゴシック）は廃止。

Google Fonts:
```
Zen+Kaku+Gothic+New:wght@500;700;900
```

## 💠 UI スタイル指針

- **フラット＆ネオブルータリズム**: カードは黒枠＋ドロップシャドウ、白背景のはっきりした構成
- **角丸は控えめ**: 装飾的な丸みは排し、直線的でシャープな印象に（ボタンはピル型を一部維持）
- **太い罫線・くっきりした境界**: ボーダーは 2px・黒を基本に、コントラストを強く
- **大きな余白とタイポグラフィ**: 見出しを大きく太く、余白をたっぷり取った雑誌的レイアウト
- **装飾エフェクトの排除**: 旧デザインのグラスモーフィズム・グロー・きらめき（sparkle）・フォググレインは撤去
- **既存 UI 構造の維持**: サイドバーのナビゲーション構成・カード構造など既存コンポーネントの骨格はそのまま活かし、配色とタイポグラフィのみ刷新
- ❌ カスタムカーソルは **使用しない**
